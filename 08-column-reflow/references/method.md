# 方法说明（08）

## 1. 为什么要用真值
"读起来通顺"不能证明顺序对。本包用**生成器造一份阅读顺序已知的双栏 PDF**（`examples/tools/make_demo.py`），每段带 `[[P1]]` 标记，真值写进 `truth.json`。算法输出与真值逐段比对，得到位置命中率、逆序数、相邻错位数——这三项可以重复计算，不依赖主观判断。

## 2. 排序规则
1. 通栏块（宽 > 0.6W 或横跨栏间留白）单独成"带边界"。
2. 每条带内：第 1 栏自上而下 → 第 2 栏自上而下 → …；带间按 y 递增。
3. 通栏块插入其所在 y 位置（标题在最上、跨栏图在其高度）。
这正好还原双栏论文的阅读习惯：先把左栏读完再读右栏，跨栏元素回到它出现的位置。

## 3. 为什么朴素顺序会错
按 `y0` 再按 `x0` 排序会把左右栏"逐行交错"：左 1、右 1、左 2、右 2…… 句子在栏间断开，就是常见的"串栏"。演示文档上它的位置命中率约 30%、逆序 20 处、相邻错位 18 处。

## 4. 清理规则
- 页眉页脚：上 7% / 下 8% 且跨页重复 ≥2 次 → 剔除（本演示 4 条）。
- 断词：行末 `-` 拼接；同栏续段：无句末标点 + 小写开头 + 间距 ≤1.6 倍字号。
- 串栏自检：同页左栏末尾无句末标点就直接转右栏 → 记 `suspicious`。

## 5. 已知边界
- 三栏以上按 x 聚类，但栏宽不等、栏间插入图时可能误判，需人工核 `layout`。
- 不做表格结构、公式符号还原、OCR。
- 生成器造的 PDF 是理想排版；真实期刊的双栏常有浮动体，需按 `suspicious` 复核。
