# 双栏阅读顺序重排

## 0. 单点

**只做阅读顺序**：把双栏 PDF 的块排成人类阅读顺序（先左栏整栏，再右栏；通栏标题/跨栏图按位置插入），并给出每段的页码与区块坐标供回查。不做表格结构、不做公式识别、不做 OCR。

## 1. 何时触发

"解析出来句子串了""左栏最后一句接到右栏第一句""双栏论文读不通""整页文本没法用"。
不触发：单栏文档（可用但没必要）、扫描件（先去 OCR）。

## 2. 输入与输出

输入：`/input/case.json`、`/input/task.md`、真实 PDF（**不得用预抽取文本冒充**）。

输出 `/app/output/`：

| 文件 | 内容 |
|---|---|
| `paragraphs.jsonl` | 每行 `{id,page,col,bbox,text,order_index}`，顺序即阅读顺序 |
| `reflow.json` | 文档级：页数、栏数判定、剔除的页眉页脚、串栏疑似位置、覆盖率 |
| `reflow.md` | 人读版，`[P0001] p.2 L` + 文本 |
| `result.json` | 契约字段 `case_id` + `status` + `metrics`，由 `scripts/run.py` 按真值复算产出 |

## 3. 流程

**第 1 步 版面判定（脚本，不靠模型猜）**
```
python scripts/reflow.py --pdf paper.pdf --out /app/output --audit
```
- 用 PyMuPDF 取块（bbox + 行文本），先算左右栏：左栏块 `x1 < 0.55W`、右栏块 `x0 > 0.45W`，中间留白 ≥4pt 才判双栏。
- 通栏块（宽 > 0.6W，或横跨栏间留白）：标题、摘要、跨栏图、宽表。
- 无可靠双栏证据时按单栏处理，并在 `reflow.json` 写 `layout=single`，不要硬分栏。

**第 2 步 排序（核心）**
用通栏块按 y 切横向带；每条带内 **左栏自上而下 → 右栏自上而下**；带与带之间按 y 递增。这样标题在顶部、跨栏图在其所在高度插入，左右栏不会交错。

**第 3 步 清理**
- 页眉页脚：上下 7% 区域内的三类文本全部剔除并记入 `dropped`（含 `reason`）：① 跨页逐字重复；② 页码形态（`Page N`、`N`、`N of M`、`N/M`）；③ 跨页只有数字不同的短行（running head/章节页眉，需字号小于正文字号）。只认逐字重复会漏掉每页变化的页码。
- 断词：行末 `-` 直接拼接（`micro-` + `structure` → `microstructure`），避免把单词拆两段。
- 同栏续段：上一块无句末标点、下一块小写开头、垂直间距 ≤1.6 倍字号时合并。

**第 4 步 自检（脚本）**
```
python scripts/reflow.py --pdf paper.pdf --out /app/output --audit
```
硬门槛：

| 指标 | 门槛 |
|---|---|
| 段落覆盖率 | 正文块全部进入输出（无遗漏） |
| 串栏疑似数 | 0（同一页左栏末尾无句末标点直接转右栏，即报可疑） |
| 页眉页脚泄漏 | 0 |
| 单页顺序可解释性 | 每段可给出 col 与 bbox，人能按坐标核对 |

**第 5 步 交付**
`status`：`success`（双栏判定成立且 audit 0 可疑）/ `partial`（有可疑段落，列出 id）/ `cannot_determine`（无文字层或栏数无法判定）。

## 4. 预算与降级

纯脚本，不耗模型请求。页数 >200 时按页批处理并落盘；遇到无文字层直接 `cannot_determine` + 建议 OCR。

## 5. 异常

| 情况 | 处置 |
|---|---|
| 三栏及以上 | 按 x 聚类成 n 栏，仍按"带内左→右"；栏数写入 `reflow.json` |
| 跨页续接 | 上页末段无句末标点、下页首段小写开头 → 下页首段记 `continues_from`（上页末段 id），并在 `reflow.json.continues` 列明；不强行合并 |
| 边注/脚注 | 贴页边（`x1 ≤ 0.2W` 或 `x0 ≥ 0.8W`）且宽度 `≤ 0.3W` 的窄块标 `role=note`/`col=note`，页末输出、不进正文序列；`reflow.json.note_blocks` 留坐标 |
| 图片型表格 | 块内无文本，仅记 bbox，不猜内容 |
| 栏间留白极小 | 判定单栏并告警，避免误切 |

## 6. 自检

```
python examples/selftest.py
```
自检 **10 条**：除双栏真值、基线对照、平台入口/降级外，新增 ① 每页变化的页码（`Page 1 of 2`/`Page 2 of 2`）按页码形态剔除且正文零泄漏；② 页边窄块进 `note` 不混正文；③ 跨页断句正确记 `continues_from`。
要求：用已知真值的双栏 PDF（`examples/demo` 生成器可重建）验证：本算法输出顺序与真值 **完全一致**；朴素"按 y 再按 x"基线明显串栏（作为对照，不是分数）。
