# 基础 Agent 的典型失败（08）

| # | 失败模式 | 现象 | 本包判据 |
|---|---|---|---|
| F1 | 按 y 坐标全局排序 | 左栏最后一句直接接右栏第一句，句子断裂 | 通栏分带 + 带内左栏整栏→右栏；位置命中率与逆序对可测 |
| F2 | 通栏标题被当栏内块 | 标题插进左栏中间 | 宽 > 0.6W 或横跨留白判通栏，插在带边界 |
| F3 | 页眉页脚混入正文 | 每页开头重复期刊名/页码 | 跨页重复文本剔除（本包实测剔除 4 条） |
| F4 | 断词不合并 | "hydra-" / "tion" 两段 | 行末连字符 + 下段小写开头 → 合并 |
| F5 | 单栏文档硬分栏 | 单栏论文被切成左右两半 | 无可靠双栏证据 → `layout=single` |
| F6 | 不报可疑串栏 | 错了也不说，读者无法判断 | `--audit` 输出 `suspicious` 位置 |

对照口径：`measure.py` 用构造真值（`[[Pn]]` 标记）算位置命中率/逆序对/相邻错位，朴素 y→x 基线同法计算，二者只差排序逻辑。
