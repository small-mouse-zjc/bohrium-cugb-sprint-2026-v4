# 对照协议（08）

## 平台侧
3 个固定案例、同一 PDF 分别给基础 Agent 与本 Skill、各 3 次重复；版式类相对项用组织方白板。本包不提供案例答案。

## 本包侧
1. **同输入**：同一 PDF、同一引擎（PyMuPDF）、同一参数。
2. **真值对照**：`examples/tools/make_demo.py` 生成的文档自带 `truth.json`，可随时重建；`eval/measure.py` 输出位置命中率、逆序数、相邻错位数。
3. **基线定义**：`reflow.py --baseline` 使用"按 y 再按 x"的朴素顺序，不剔除页眉页脚。这是"整页文本流"的典型做法，用于说明差异来源，不代表基础 Agent 的真实跑分。
4. **重复性**：同一 PDF 重复运行，`paragraphs.jsonl` 应逐字节一致。
5. **不声明**：不写"提升多少分"；基线数字是本包演示文档上的实测值。

## 指标定义
- 位置命中率 = 与真值同位置的标记块数 / 真值块数
- 逆序数 = 真值中前置却在输出中后置的块对数
- 相邻错位数 = 输出中相邻但真值位置相差 >1 的块对数
