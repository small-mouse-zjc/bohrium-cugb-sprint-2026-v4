# 对照协议（10）

## 平台侧
3 个固定案例、同一两篇材料、基础 vs Skill、各 3 次重复；相对项用组织方白板。本包不提供案例答案。

## 本包侧
1. **同输入**：同一 `corpus.json` + `relations.json` + `queries.json`，只改变"是否做归一与非合并判定、是否逐字绑引文、查询是否强制带来源"。
2. **指标**：归一覆盖率、跨篇节点数、非合并判定数、边引文率、查询有证据率，全部来自 `validation.json`。
3. **重复性**：同输入重跑 `kg.json` 应一致（无随机、无字典序漂移：节点按出现顺序编号）。
4. **盲评**：只给 `kg.json` + `queries_result.json`，评审抽查每条 quote 是否为对应段落连续子串。
5. **不声明**：不做正式 RDF 推理与链接开放数据发布；不声称分数提升。

## 指标定义
- 归一覆盖率 = 成功解析到节点的提及 / 全部提及
- 边引文率 = 引文为对应段落连续子串的边 / 全部边
- 查询有证据率 = 结果带 ≥1 条证据的查询 / 全部查询（空结果必须计为失败）
- 非合并判定 = 同名同类型但身份限定冲突、被显式保留为多节点的记录数
