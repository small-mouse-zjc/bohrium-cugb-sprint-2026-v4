# 基础 Agent 的典型失败（10）

| # | 失败模式 | 现象 | 本包判据 |
|---|---|---|---|
| F1 | 大小写/连字符变体不归一 | `Gas hydrate` 与 `gas-hydrate` 成两节点，跨篇结论各说各 | 归一键统一 → 1 节点（自检 D1） |
| F2 | 同名不同样品被强行合并 | 现场样 CUG-3 与实验室 S2 混成一个"sediment sample" | 身份字段冲突 → 拆节点 + non_merge 记录（D2） |
| F3 | 引文改写/拼接 | 边存在但原文找不到这句话 | 连续子串校验 → K03，边剔除（D3） |
| F4 | 查询无结果却给结论 | 问"有没有 supports"回答"有，根据常识" | 空结果 → K04，`count=0`（D4） |
| F5 | 缩写跨篇借用 | P2 的 `DM` 用 P1 的定义解释 | 缩写只篇内解析 → K05（D5） |

灰线原则：判不了就不合并、没证据就不建边；所有"没有"都要显式写出来。
