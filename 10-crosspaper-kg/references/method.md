# 方法说明（10）

## 1. 归一键
`norm()`：NFKC → 小写 → 连字符/下划线转空格 → 去掉标点 → 压缩空白 → 末词单数化。因此 `Gas hydrate`、`gas-hydrate`、`Gas  Hydrates` 落到同一键。

## 2. 缩写解析
逐篇扫描 `全称 (缩写)` 形式，建立**篇内**映射。缩写只在本文内有定义才展开；跨篇不借用别篇定义（避免把不同论文的同一缩写当同一实体）。无定义的缩写计入 `unresolved_aliases` 并报 K05。

## 3. 合并与不合并
- 同一 `(键, 类型)` 进入候选组，再按**身份限定字段**（site / sample_id / model_id / dataset_id / conditions）拆子节点。
- 两边都给了身份字段但字段不重叠 → **不合并**（无法证明是同一实例）。
- 同一字段取值冲突 → **不合并**，写出 `non_merge` 记录：冲突字段、两侧值、规则、两侧原文证据。
- 都未给身份字段 → 合并，并在 `attrs` 留空（评审可追问，但不假装有证据）。

## 4. 边与引文
边只能由 `(主体, 关系, 客体)` + `(paper_id, paragraph_id, quote)` 构成；`quote` 必须是该段落归一空白后的连续子串，否则 K03 且该边不进入图谱。端点解析不到节点 → K06。这样"图里有这条边"永远等价于"原文里真有这句话"。

## 5. 查询
`node / edges / path / nonmerge` 四类。每个结果都带 `evidence`；`evidence` 为空即 K04 —— 空结果必须显式失败，禁止用常识补全。路径查询在 8 跳内 BFS，找不到就返回 `found:false` 而不是编造链路。

## 6. 边界
- 不做实体消歧的机器学习模型，只做规则 + 证据；规则判不了的一律不合并（保守）。
- 不解析图表数值、不做单位换算。
- `paragraph_id` 是 JATS 段落号，不是 PDF 页码，输出中不出现"第 N 页"。
