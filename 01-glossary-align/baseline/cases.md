# 基线失败夹具（构造，非平台案例）

这三类失败来自基础 Agent 在文献翻译上的稳定行为，本包把它们做成**可注入的缺陷夹具**，用于证明质检器能抓到，而不是用文字声称"比基线好"。

| 编号 | 失败模式 | 注入方式 | 期望被检出 |
|---|---|---|---|
| F1 | 术语漂移：同一术语在后文换成近义词 | P0002 的"分解压力"改成"解离压力" | `term_drift` |
| F2 | 整段漏译：长文后半段只写"其余同上"或直接缺段 | 删除 P0003 条目 | `missing_para` + 覆盖率 < 0.98 |
| F3 | 数字/标记丢失：为通顺把"6 m"写成"若干米"，把"Fig. 2"写成"图 2" | P0004 去数字、P0003 改图表标记 | `number_lost` / `citation_lost` |

说明：

1. 这不是"基础 Agent 的真实跑分"，也不能替代平台对照。它只验证**检测机制有效**——如果连注入的缺陷都抓不到，Skill 的增益就无从谈起。
2. 正式对照由平台用同一案例分别跑基础 Agent 与本 Skill，三次重复，本包不提供也不伪造白板或分数。
3. 夹具文本为自建演示文本，不含真实论文断言。
