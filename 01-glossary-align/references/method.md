# 方法说明（01）

## 1. 段落编号为什么先定

译文一旦重排，任何"第 3 段漏了"的判断都失去锚点。所以 `pdf_to_paras.py` 先产出 `P0001..` 并写入 `bbox/page/col/section`；后续翻译、质检、回查都只用这个编号，禁止按译文顺序重新编号。

## 2. 版面处理

- **双栏**：按块 bbox 把页面分成 span / L / R；用通栏块（标题、跨栏图表）把页面切成横向带，带内先左栏自上而下、再右栏自上而下。这是双栏论文的正确阅读顺序。
- **页眉页脚**：位置在上 8% / 下 8%，且归一化文本跨页重复 ≥2 次，剔除并记入 `dropped_headers_footers`。
- **断词**：行末 `-` 判断为断词时直接拼接（`hyphen-\nation` → `hyphenation`），避免把 `micro-` 和 `structure` 拆成两段。
- **同栏续段**：上一块没有句末标点、下一块小写开头、垂直间距小于 1.6 倍字号时合并。
- **无文字层**：`chars_per_page` 平均 < 50 时置 `status=no_text_layer`，要求 OCR，不输出空白正文。

## 3. 术语为什么"锁"

`glossary.py lock` 拒绝三类输入：空译名、同一源词两个译名、同一译名对应两个源词（同义合并必须写理由）。锁定后术语表成为**硬约束**：`qc.py` 对每段做"源段出现该词 → 译文必须含锁定译名"的检查，违反即 `term_drift` 并给出行号段落。

## 4. 质检的五个比率

| 指标 | 定义 | 门槛 | 为什么这个门槛 |
|---|---|---|---|
| 覆盖率 | 有非空译文段落 / 源段落 | 0.98 | 允许极少数不可译段落，但不允许整段消失 |
| 术语一致率 | 命中锁定译名次数 / 应命中次数 | 1.00 | 术语表是强制的，1 次漂移就是缺陷 |
| 数字保真率 | 原样保留的数字 / 源数字 | 0.95 | 允许全半角差异，不允许"约""若干"替换 |
| 引用保真率 | 保留的 `[n]/Fig./Table/Eq.` / 总数 | 1.00 | 引用错位比措辞不通更致命 |
| 未确定标注率 | 带 risk 的非 ok 段落 / 非 ok 段落 | 1.00 | 不许把不确定写成事实 |

## 5. 已知边界

- 不能判断译文文采、学科习惯表达是否地道；这需要人工盲评。
- 扫描件不做 OCR，只报 `no_text_layer`。
- 公式为图片时只能标注，不能转写 LaTeX。
- 希腊字母、上下标在纯文本流中可能平化，需在 `risk` 里说明。
