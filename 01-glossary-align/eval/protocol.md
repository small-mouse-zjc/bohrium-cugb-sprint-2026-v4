# 对照协议（本题 01）

## 平台侧（正式评分）

平台固定 3 个案例，同一输入分别交基础 Agent 与加载本 Skill 的 Agent，每条件重复 3 次；需要相对比较的维度用组织方白板。**本包不提供、不伪造案例答案、白板或分数。**

## 本包侧（自证增益的合法边界）

1. **公平性**：对比两份结果时，输入段落完全一致（同一 `paras.jsonl`），术语表口径一致（同一 `glossary.csv`），只改变"是否执行锁定与质检"。
2. **可比指标**：五项比率全部由 `scripts/qc.py` 在同一口径下计算；`eval/metrics.py` 只做读取与相减，不做估算。
3. **重复性**：同一输入重跑 3 次，段落编号与覆盖率必须完全一致；译文措辞允许差异，但术语一致率与数字保真率不得下降。
4. **盲评**：如有人工评分，评审只看 `bilingual.md`，不看哪份来自 Skill；术语表另附供核对。
5. **不做的声明**：不声称"提升 X 分"，不编造基线分数；基线只以注入缺陷夹具证明检测能力。

## 指标定义

- 段落覆盖率 = 有非空译文且状态不为 untranslatable 的段落 / 源段落总数
- 术语一致率 = 源段出现锁定术语且译文含其锁定译名的次数 / 源段出现锁定术语的次数
- 数字保真率 = 源段数字标记在译文中原样出现的个数 / 源段数字标记总数
- 引用标记保真率 = `[n]`、`Fig./Table/Eq./Section n`、`(Author, year)` 保留数 / 总数
- 未确定标注率 = 非 ok 段落带 risk 说明的个数 / 非 ok 段落数（无非 ok 段落时记 1.00）
