# 对照协议（05）

## 平台侧
3 个固定案例、同一份材料分别给基础 Agent 与本 Skill、每条件 3 次重复。本包不提供案例答案或白板。

## 本包侧
1. **同输入**：同一 `methods.md`、同一 `params.json`、同一组来源文件、同一 `manifest.json`/`steps.json`。
2. **指标**：有源参数率、无源数值数、冲突值数、复现九项覆盖、步骤四要素完整率、限制具体率，全部由脚本计算。
3. **重复性**：同输入重跑，`params.csv` 与 `repro.json` 必须逐字节稳定（脚本无随机性）。
4. **盲评**：只看 `methods.md` 与 `params.csv`，不看来源目录，评审据此判断"能否复做"。
5. **不声明**：不写"提升多少分"；缺陷夹具只证明检测能力。

## 指标定义
- 有源参数率 = `status=sourced` 行 / 台账行
- 无源数值数 = `status=unsourced` 行 + 带单位但全库找不到的数值个数
- 冲突值数 = `status=conflict` 行
- 复现九项覆盖 = 已具备项 / 9（代码版本、环境、依赖、硬件、数据获取、数据版本与划分、种子、命令、轮次与耗时）
- 步骤四要素完整率 = 输入/操作/输出/判断四项齐全的步骤 / 步骤总数
- 限制具体率 = 含条件词或数值的限制 / 限制条数
