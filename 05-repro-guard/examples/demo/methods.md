# 3 方法与实验

## 3.1 数据与划分

使用公开的岩心 CT 数据集，按 8:1:1 划分训练、验证与测试集，数据版本为 v2.3，随机种子设为 42。

## 3.2 训练设置

训练在单张 A100 上完成，学习率为 0.001，批大小为 32，共训练 50 轮。前若干轮采用线性预热，之后余弦衰减。优化器为 AdamW，权重衰减为 0.01。

## 3.3 评价

以孔隙度预测的均方误差为指标，在测试集上报告重复实验的均值与标准差。

## 3.4 限制

方法仅适用于体素分辨率不低于 2 μm 的 CT 图像。样本岩心少于 50 个时，验证集规模不足，指标波动会超过 0.005。
