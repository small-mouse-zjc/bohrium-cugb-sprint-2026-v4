# 对照协议（09）

## 平台侧
3 个固定案例、同一论文材料、基础 vs Skill、各 3 次重复；相对项用组织方白板。本包不提供案例答案。

## 本包侧
1. **同输入**：同一 `sources.json`、同一论文元数据，只改变"是否按原子断言 + 逐字证据 + 四层导出"。
2. **指标**：断言原子率、证据逐字率、来源完整率、导出回解析是否一致，全部由 `validation.json` 给出。
3. **重复性**：同输入重跑，`nanopub.trig` 应逐字节一致（生成器无随机性）。
4. **盲评**：只看 `assertions.json` 与 `nanopub.trig`，评审逐条回原文核对。
5. **不声明**：不做数字签名，不声称是正式 Nanopublication 网络上的已发布件；不写"提升多少分"。

## 指标定义
- 原子率 = 通过 N01 的断言 / 断言总数
- 逐字证据率 = 证据为源段落连续子串且长度合规的断言 / 总数
- 来源完整率 = 具备 title/year/paragraph_id（及 doi 或 doi_reason）的断言 / 总数
- 导出回解析 = 命名图数、assertion 节点数、quote 数均等于断言数
