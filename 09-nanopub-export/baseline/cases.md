# 基础 Agent 的典型失败（09）

| # | 失败模式 | 现象 | 本包判据 |
|---|---|---|---|
| F1 | 一句多断言 | "X 增加且 Y 降低"写成一条，无法判真假 | N01 并列连接词/多句 → 拒 |
| F2 | 转述当证据 | quote 与原文语义近但字面不同 | N02 连续子串校验 |
| F3 | 整段当证据 | 400+ 字大段，无法定位 | N03 长度 10–400 |
| F4 | 证据不含主体 | 引一句无关的话凑数 | N04 须含主体或客体表面形式 |
| F5 | 缺来源 | 无段落号/无 DOI 也无说明 | N05 |
| F6 | 关系词自由发挥 | "affects"、"impacts" 混用 | N06 受控词表 |
| F7 | 重复断言 | 同一结论出现两次，计数虚高 | N07 |
| F8 | 导出不可读 | 自称 JSON-LD 但缺 @context/命名图 | N08 回解析 |
