# 对照协议（04）

## 平台侧
3 个固定案例、同输入、基础 vs Skill、每条件 3 次重复、相对维度用组织方白板。本包不提供案例答案与白板。

## 本包侧
1. **同输入**：同一 `works.json`、同一 `dimensions.json`、同一 `manuscript.json`，只改变"是否先建矩阵并按矩阵写"。
2. **可计算指标**：分组结构、维度填充率、论断挂引用率、空白支撑率、关键文献覆盖、贡献证据率，全部由脚本算出，`eval/metrics.py` 只做汇总。
3. **重复性**：同输入重跑，矩阵与 `bind.json` 的比率必须一致；文字表述可不同。
4. **盲评**：评审只看 `intro_draft.md` 与 `matrix.md`，不知道哪份来自 Skill；引用清单另附。
5. **不声明**：不写"提升多少分"，不伪造基线；缺陷夹具只证明检测能力。

## 指标定义
- 论断挂引用率 = 带引用标记的论断句 / 论断句总数（论断判定见 `references/method.md`）
- 悬空引用 = 引用了 `works.json` 中不存在的 wid 的次数
- 关键文献覆盖 = 被引用的 `key=true` 文献 / 全部关键文献
- 空白支撑率 = 引用 ≥2 篇该空白支撑文献的空白句 / 空白句总数
- 贡献证据率 = 指向材料中真实存在的 §/Fig./Table 的贡献 / 贡献总数
