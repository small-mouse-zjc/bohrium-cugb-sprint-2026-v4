# 基线失败夹具（04）

四类失败是基础 Agent 写引言的常见形态，做成可注入缺陷，用来证明核对器有效——不是声称"基础 Agent 只能得多少分"。

| 编号 | 失败模式 | 注入方式 | 期望检出 |
|---|---|---|---|
| F1 | 论断无引用：数字/比较/因果句凭印象写 | 删掉"3.2 MPa"后的 `[W1]` | `claim_uncited` |
| F2 | 悬空引用：引了文献表里没有的条目 | 追加 `[W9]` | `dangling_citation` |
| F3 | 空白单篇支撑：用一篇的局限硬写"没人做过" | 空白句 `[W4][W6]` 改为 `[W4]` | `gap_unsupported` |
| F4 | 贡献证据不存在：写"见 Table 3"，材料里只有 Table 1 | 改证据编号 | `contribution_evidence_missing` |

正式对照由平台跑；本包不提供案例答案、白板或分数。夹具文本为自建演示，条目为虚构编号（见 `examples/demo/works.json` 的 note）。
